# Y 姿態關鍵幀方法比較

主要姿態已經接受、需要測試時間與過渡層時，改用[固定主要姿態的過渡研究](pose-transition-research.md)，不再透過本入口重選主要格。

本頁是多方法比較用的研究入口；正常真人動作製作使用[正式姿態選幀](pose-sampling.md)，不由 Codex 逐段編排研究命令。比較原型不修改 X，不宣稱精確重現論文或對所有媒材皆最佳。

獨立研究環境安裝 mediapipe，使用官方 Pose Landmarker Full task 模型。本機推論，不上傳素材。一次連續擷取所有來源格，再讓不同方法共用同一份 landmarks；主幹、雙臂、雙腿與足部採對稱固定關節集合，不依動作名稱偏重某側。只作一次共同尺度換算，不逐幀拉齊高度，也不刪掉自然位移。快取以影片、模型內容雜湊與區間驗證；漏格立即停止並回報，不由 Codex 手補。

`python scripts/benchmark_pose_methods.py --video VIDEO --model POSE_MODEL --start START --end END --output RESEARCH_FOLDER --analysis-masks ORIGINAL_ANALYSIS_MASK_FOLDER`

analysis-masks 指向既有選段分析的原尺寸 Alpha 及 analysis.json，不新增審查圖片，也不重新去背。存在關節遮擋時必須提供；全部關節可靠時可省略。

報告含原始 landmark 可見度、各方法來源索引、數值重建誤差與決策軌跡。方法包括：遞迴軌跡簡化（噪聲估計門檻）、多尺度曲率顯著性、速度低點，以及 BIC 懲罰的時間連續姿態分群。另比較遞迴法的自動曲線轉折停止：遞迴加入最大誤差來源格，對整條誤差—張數曲線正規化，選改善量相對複雜度成本最大的轉折位置，不指定張數。這是轉折概念的簡化原型，不是完整 Kneedle 論文實作。

研究結果需要先評估主要動作階段覆蓋，再比較冗餘、執行成本及自動化程度。重建誤差只作數值診斷，不等於 sprite 停格播放品質。不可用來源標註來調關節權重、指定格數或挑門檻；可以用標註獨立評估。Codex 只在研究初期核對少量候選或異常，不作正常流程的逐格選擇者。

姿態輸入先檢查完整度與有限數值。visibility 低於 0.5 的關節標為不可觀測，不採信該座標；不以單一肢體區域平均分數否決整段。主要方案 recursive_automatic_knee 用可觀測關節做時間平滑，插值誤差只比較來源格與區間兩端共同可觀測的關節。

缺少的關節資訊由原始人物 RGB／Alpha 補充：使用區間共用包圍框，固定 48×64、RGB 先乘 Alpha，保留人物內部變化及輪廓，不逐幀對齊或放大。影像誤差按該區間影像振幅正規化至姿態振幅尺度，乘以本次比較缺失的關節比例，再與可見關節誤差取最大值；資訊少不能自動等於沒動。沒有共同可見關節時仍可用影像證據；缺少所需影像或資料損壞則停止，不猜補關節。全部關節可靠時影像補充分數為零，沿用既有結果。共同尺度優先用可靠軀幹，沒有可靠軀幹格則使用可見關節範圍，完全只有影像時使用影像尺度。

benchmark 保存數值 appearance.npz 與來源影片、遮罩、對應表的雜湊契約供補幀重用；沒有輸出額外審查圖。報告保存規則版本及低可信格。其它四種比較原型仍用未加權距離，不當成遮擋替代方案。

目前快取與時間取樣以 CFR 影片為研究範圍；正式接入前仍需增加來源 PTS／VFR、非真人及不同動作驗證。影像補充只能反映可見變化，不能還原完全隱藏的動作，也未涵蓋高信心錯誤、遮罩錯誤與骨架跳點。MediaPipe 不列入正常製作必需依賴，避免研究套件影響現有環境。
