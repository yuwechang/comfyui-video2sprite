# 安裝與更新（供 Codex 執行）

使用者提供 GitHub 儲存庫網址並要求安裝時，先讀取該儲存庫的 `SKILL.md`，確認技能名稱與位置。本儲存庫的 Skill 位於根目錄，名稱為 `comfyui-video2sprite`。

## 安裝

優先使用可用的 `skill-installer`。由工具處理下載；儲存庫根目錄作為來源時，明確指定安裝名稱 `comfyui-video2sprite`。依當前 Codex 支援的技能搜尋位置安裝，個人安裝可使用 `~/.agents/skills/comfyui-video2sprite/`；使用者指定專案範圍時使用該專案的 `.agents/skills/`。

沒有安裝工具時，由 Codex 下載儲存庫，將 `SKILL.md`、`requirements.txt`、`scripts/` 與 `references/` 放入同一個安裝資料夾。確認腳本與參照完整，不複製開發機的 `.local/`、`work/` 或 `outputs/`。不要求使用者自行搬移檔案或輸入終端命令。

若已存在同名技能，先確認是更新要求還是重複安裝；不要把一份安裝嵌套在另一份裡。安裝後確認 Codex 能找到技能；尚未出現時才請使用者重新開啟對話或重新啟動 Codex。

## 環境與首次設定

在使用者的工作資料夾執行安裝目錄內的 `scripts/setup.py check`，使用腳本完整路徑。若尚未指定工作資料夾，詢問存放位置。

找可用的 Python 3.10 以上；缺少時說明並詢問是否協助安裝。需要隔離套件時建立任務的虛擬環境，以同一個 Python 安裝 `requirements.txt` 並執行後續腳本。

只安裝缺少的依賴。缺少 FFmpeg 或 ffprobe 時，說明這是外部依賴且 Skill 不隨附，詢問是否協助安裝；同意後依平台安裝、確認可呼叫，再重新執行檢查。不下載未經請求的模型或更動 ComfyUI 節點。

技能安裝與 ComfyUI 連線分開判定。ComfyUI 未啟動時告知使用者先啟動；連不上預設網址時才詢問網址，依 [環境與工作流對接](setup.md) 接續首次設定。工作流 JSON、節點對應、任務與成品存於工作資料夾，不寫進技能安裝目錄。

回報安裝與環境檢查結果，指出尚待使用者提供的項目。沒有實際對接或生成時，不將工作流列為已驗證。

## 更新

依使用者提供的儲存庫取得新版本，檢查其技能結構與必要檔案後更新同一個安裝位置。保留使用者工作資料夾的工作流設定、素材、任務與成品。以更新後的套件清單檢查依賴，只處理新增或缺少的項目，再確認技能可讀取。
