# 影片生成

依[角色與動畫計畫](character-plan.md)取得本任務姿態、環境與 `entry_reference`。製作 Idle 時用已確認的姿態演出版面；地面動作使用對應 Idle 的來源基準，空中動作則使用已保存的完整空中基準圖。生成寬高與對應畫布一致，保留角色比例、位置與留白。第二張圖片的用途及省略方式由本機工作流設定決定。

編寫前讀取[前段提示詞參考](prompts.md)，依工作流輸入模式填入模型格式、動作主體及需要的站位、結束與特效段，保存為 UTF-8 檔案。角色外觀、畫風、朝向、固定全身鏡頭與目前姿態由實際輸入確定；姿態與環境不因動作名稱改變。Idle 本身呈現可銜接的呼吸或細微重心動作，不以靜止圖片代替。依[動作類型定義](spritesheet.md)描述結束行為；返回起始是回到本任務的起始基準，不固定等於地面 Idle。起收及目標姿態需足夠清楚，演出需保有可辨識的動作過程與節奏。跳躍來源與空中片段的階段要求見[空中處理](airborne.md)。

來源長度足以容納多次短動作時，可依提示詞參考的獨立重複段利用剩餘演出時間，每次先完整回復再出招；不將單次出招拖滿整支影片，也不將此策略套到循環運動或保持結束姿態的動作。次數是生成引導，不是成品要求，來源有完整可用區間即可進入後段，不因沒有精確達到次數而重試。原地動作的自然轉腳、屈膝、重心轉移或必要換步不等於滑移，沿用該文件的站位段時須保留這些合理運動。

特效依演出意圖選擇無效果、打擊或尾跡，不為所有動作加效果。使用[特效版型](prompts.md#特效先選類型再寫入有效攻擊段)，填入當次可辨識的作用部位、局部尺寸、方向與路徑，將效果綁定有效攻擊段。打擊優先局部白色空壓脈衝；尾跡跟隨實際攻擊路徑，保留外緣與內層、尾端淡出描述。效果不得取代角色與實體裝備細節；合理路徑造成的交疊依整段運動判讀，不強制每張畫面相同前後層次。使用者要求無效果或特定演出時依其要求，不以追求特效外觀改變動作。

前段只負責準備及檢查來源影片，不執行逐張 Refine、去特效、Alpha 清理或成品裁切。取得影片後，Codex 檢視動作區段中的手腳、髮絲、飄帶與裝備，武器另查刀刃、劍尖、槍尖、握柄及手部連接。效果位於輪廓外或薄透明重疊、原內容仍清楚可辨時，可以交給後段清理；若強光飽和或不透明效果取代了肢體與武器內容，不把後段重建當成可保證能力。選用其他合適區間；沒有完整區間時，調整來源生成或回報限制，不自動反覆重試。

依[提示詞檢查與調整](prompts.md#檢查與有依據的調整)檢查整段演出、起收、節奏、站位、效果階段與完整性；有疑義才補看少量連續影格，不能只依單張姿態判斷預備與攻擊。將結論依[檢查紀錄](spritesheet.md#檢查紀錄)保存於本次前段任務目錄。未要求穩定度測試時不自動多種子批次；要求測試時固定提示詞與其它條件、保留實際種子及所有結果，不混淆預計數與已完成數。後段只接收影片及明確參數，不要求讀取這份前段紀錄。

執行：

```text
python scripts/generate.py --profile .local/profile.json --job work/action/job --image character.png --prompt-file work/action/prompt.txt --width 768 --height 768 --seconds 2.4 --seed 42
```

寬、高與秒數依本次動作需要指定。這裡的秒數為來源影片長度；程式依設定向上對齊至合法影格數。需要第二張圖片時加 `--image2`。

程式在工作副本中套用輸入，僅保留指定輸出及其依賴，提交一次，透過 WebSocket 等待完成，必要時本機補查 history，下載影片並以 ffprobe 確認可讀取。完整資料寫入工作目錄，標準輸出回傳完成摘要。

已存在任務 ID 的工作目錄可用同一命令接續等待，不重新生成。狀態為 `submitting` 且沒有 ID 時，需檢查佇列確認是否已接受，才決定後續操作。

取得影片後，執行 `python scripts/check_video_bounds.py video.mp4`，由 Python 本機掃描並回報疑似碰邊方向與影格索引。這是簡單背景的輔助檢查，複雜背景可能無法判定；Codex 檢視原尺寸影格確認是否截斷。確定超框時，缺失內容無法靠後續裁切補回；回到圖片預處理，保持角色尺度，沿不足方向提高一級追加留白後，在新任務目錄重新生成。左右不足時左右對稱增加，上方不足只加上方；不自動反覆重試。
