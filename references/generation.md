# 影片生成

使用已檢視通過的預處理圖片。生成寬高與該演出畫布一致，保留已建立的角色比例、位置與留白。第二張圖片的用途及省略方式由本機工作流設定決定。

將提示詞存為 UTF-8 檔案，分別描述角色與風格、維持目前場景、固定全身鏡頭，以及完整動作順序；需要時交代不加特效。執行：

```text
python scripts/generate.py --profile .local/profile.json --job work/action/job --image character.png --prompt-file work/action/prompt.txt --width 768 --height 768 --seconds 2.4 --seed 42
```

寬、高與秒數依本次動作需要指定。這裡的秒數為來源影片長度；程式依設定向上對齊至合法影格數。需要第二張圖片時加 `--image2`。

程式在工作副本中套用輸入，僅保留指定輸出及其依賴，提交一次，透過 WebSocket 等待完成，必要時本機補查 history，下載影片並以 ffprobe 確認可讀取。完整資料寫入工作目錄，標準輸出回傳完成摘要。

已存在任務 ID 的工作目錄可用同一命令接續等待，不重新生成。狀態為 `submitting` 且沒有 ID 時，需檢查佇列確認是否已接受，才決定後續操作。

取得影片後，執行 `python scripts/check_video_bounds.py video.mp4`，由 Python 本機掃描並回報疑似碰邊方向與影格索引。這是簡單背景的輔助檢查，複雜背景可能無法判定；Codex 檢視原尺寸影格確認是否截斷。確定超框時，缺失內容無法靠後續裁切補回；回到圖片預處理，保持角色尺度，沿不足方向提高一級追加留白後，在新任務目錄重新生成。左右不足時左右對稱增加，上方不足只加上方；不自動反覆重試。
